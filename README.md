# אתר וילה קיסריה

אתר הצגה והשכרה לוילה אחת, בהשראת lecollectionist.com. כולל עברית/אנגלית עם תמיכה מלאה ב-RTL, יומן זמינות ומחירים דינמי, וטופס פנייה. כולל פאנל ניהול (`admin.html`) לעריכת תוכן, תמונות ויומן — עם נתונים חיים ב-Supabase, כך שכל שינוי מופיע מיד באתר החי מכל מכשיר.

הדפלוי החי: Netlify (frontend) + Supabase (מסד נתונים, אחסון תמונות, והתחברות אדמין), מחוברים דרך GitHub.

## איך זה עובד

- **`index.html` / `js/site.js`** — האתר הציבורי. טוען את התוכן, התמונות והיומן מ-Supabase בכל טעינה, ומאזין לשינויים בזמן אמת (Realtime) כך שאם האדמין משנה מחיר או סוגר תאריך, זה מתעדכן באתר החי בלי רענון.
- **`admin.html` / `js/admin.js`** — פאנל הניהול. התחברות דרך Supabase Auth, וכל עריכה (תוכן, תמונות, יומן) נכתבת ישירות ל-Supabase.
- **`js/data.js`** — שכבת התקשורת עם Supabase (קריאה וכתיבה של תוכן/תמונות/יומן).
- **`js/config.js`** — כתובת פרויקט ה-Supabase והמפתח הציבורי (anon key). המפתח הזה בטוח לחשיפה בצד הלקוח — הוא לא מאפשר יותר ממה שמדיניות ה-RLS (Row Level Security) בבסיס הנתונים מתירה.

## יצירת משתמש אדמין (פעם אחת)

הכניסה לפאנל הניהול מנוהלת ע"י Supabase Auth ולא ע"י סיסמה מקומית. כדי ליצור את המשתמש הראשון:

1. כנסו ל-[לוח הבקרה של Supabase](https://supabase.com/dashboard) → הפרויקט שלכם → **Authentication** → **Users**.
2. לחצו **Add user** → **Create new user**.
3. הזינו את האימייל שלכם (למשל elad.hollander24@gmail.com) וסיסמה.
4. חשוב: סמנו **Auto Confirm User**, אחרת המשתמש ידרוש אימות אימייל לפני שיוכל להתחבר.
5. היכנסו ל-`admin.html` באתר עם אותו אימייל וסיסמה.

ניתן להוסיף מנהלים נוספים באותה דרך, ולשנות סיסמה קיימת מתוך לשונית "הגדרות" בפאנל הניהול לאחר ההתחברות.

## מבנה הנתונים ב-Supabase

בפרויקט (`uejyczokelaoiwhmcayw`) הוקמו הטבלאות:

- **`site_content`** — שורה יחידה עם התוכן בעברית ואנגלית (JSON), מחיר בסיס, מינימום לילות, ואימייל ליצירת קשר.
- **`calendar_days`** — שורה לכל תאריך עם override (מחיר מיוחד ו/או סגור), רק לתאריכים שחורגים מברירת המחדל.
- **`villa_images`** — רשימת תמונות הגלריה, כולל איזו מהן היא ה"הירו" הראשית.
- **Storage bucket `villa-images`** — תמונות שמועלות דרך פאנל הניהול (התמונות המקוריות של הוילה יושבות כקבצים סטטיים בתיקיית `images/` ומוגשות ע"י Netlify).

הרשאות (RLS): כולם יכולים לקרוא (כדי שהאתר הציבורי יעבוד), רק משתמש מחובר (authenticated, כלומר האדמין) יכול לכתוב.

## הרצה מקומית

```bash
cd villa-website
python3 -m http.server 8000
```

ואז גלשו אל `http://localhost:8000`. פאנל הניהול נמצא ב-`http://localhost:8000/admin.html`. גרסת ה-localhost מתחברת לאותו פרויקט Supabase כמו האתר החי — כלומר שינויים שתעשו כאן יופיעו גם באתר האמיתי.

## מה אפשר לעשות בפאנל הניהול

- **תוכן האתר** — עריכת שם הוילה, תיאור, מספרי חדרים/אורחים ורשימת המתקנים, בנפרד לעברית ולאנגלית.
- **תמונות** — העלאת תמונות חדשות (נשמרות ב-Supabase Storage), הגדרת תמונת ה"הירו" הראשית, ומחיקת תמונות.
- **יומן ומחירים** — לחיצה על תאריך התחלה ותאריך סיום ביומן, ואז קביעת מחיר ללילה לטווח, סגירת תאריכים (לא זמין) או פתיחתם מחדש.
- **הגדרות** — מחיר בסיס, מינימום לילות, אימייל לקבלת פניות, ושינוי הסיסמה שלכם.

## מה עדיין לא מחובר לשרת

- **טופס הפנייה** באתר הציבורי פותח את תוכנת המייל של המבקר (mailto) עם פרטי הפנייה ממולאים מראש. זה עובד, אבל אם תרצו שהפניות יישמרו גם במסד הנתונים או יישלחו אוטומטית (למשל דרך Resend), אפשר להוסיף טבלת `inquiries` ופונקציית Edge Function ב-Supabase לשליחת מייל בפועל — בקשו ואבנה את זה.
