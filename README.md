# אתר וילה קיסריה — דמו

אתר הצגה והשכרה לוילה אחת, בהשראת lecollectionist.com. כולל עברית/אנגלית עם תמיכה מלאה ב-RTL, יומן זמינות ומחירים דינמי, וטופס פנייה. כולל פאנל ניהול (`admin.html`) לעריכת תוכן, תמונות ויומן.

## הרצה מקומית

זהו אתר סטטי (HTML/CSS/JS ללא שרת). כדי שהזיכרון המקומי (localStorage) יעבוד בצורה תקינה בין העמוד הציבורי לפאנל הניהול, מומלץ להריץ שרת מקומי פשוט ולא לפתוח את הקבצים ישירות מה-Finder:

```bash
cd villa-website
python3 -m http.server 8000
```

ואז גלשו אל `http://localhost:8000`. פאנל הניהול נמצא ב-`http://localhost:8000/admin.html` (יש גם קישור "Admin" בתחתית האתר).

## כניסה לפאנל ניהול

- שם משתמש: `admin`
- סיסמה: `caesarea2026`

ניתן לשנות שם משתמש וסיסמה בלשונית "הגדרות" לאחר ההתחברות.

## מה אפשר לעשות בפאנל הניהול

- **תוכן האתר** — עריכת שם הוילה, תיאור, מספרי חדרים/אורחים ורשימת המתקנים, בנפרד לעברית ולאנגלית.
- **תמונות** — העלאת תמונות חדשות (נשמרות בדפדפן), הגדרת תמונת ה"הירו" הראשית, ומחיקת תמונות.
- **יומן ומחירים** — לחיצה על תאריך התחלה ותאריך סיום ביומן, ואז קביעת מחיר ללילה לטווח, סגירת תאריכים (לא זמין) או פתיחתם מחדש.
- **הגדרות** — מחיר בסיס, מינימום לילות, אימייל לקבלת פניות, ושינוי פרטי ההתחברות.

כל שינוי שנשמר בפאנל הניהול מופיע מיד באתר הציבורי (באותו דפדפן).

## חשוב להבין — זוהי גרסת דמו

זהו פרוטוטייפ מלא ופונקציונלי לצורך הדגמה, ולא מערכת production מוכנה לאתר חי:

1. **האחסון הוא מקומי לדפדפן (localStorage).** כל התוכן, התמונות והיומן נשמרים בדפדפן הספציפי שבו נעשה השימוש — לא במסד נתונים מרכזי. אם תפתחו את האתר בדפדפן אחר, בטלפון אחר, או תנקו את היסטוריית הדפדפן — התוכן יחזור לברירת המחדל. זה מספיק כדי להדגים את חוויית המשתמש והניהול, אך לא מתאים לאתר חי שבו אורחים אמיתיים צריכים לראות את אותה זמינות בכל מכשיר.
2. **ההתחברות לאדמין היא הצפנה בסיסית בלבד**, לא רמת אבטחה של מערכת production אמיתית.
3. **טופס הפנייה** פותח כרגע את תוכנת המייל של המבקר (mailto) עם פרטי הפנייה ממולאים מראש — הוא לא שולח בקשה לשרת ולא שומר את הפנייה במקום מרכזי.

### כדי להעלות את זה לאתר חי אמיתי

כשתרצו להפוך את זה לאתר production אמיתי (עם דומיין, יומן זמינות משותף לכולם, והתחברות אדמין מאובטחת), יידרש:

- **Backend + מסד נתונים** (למשל Node/Next.js + PostgreSQL, או Firebase) לשמירת התוכן והיומן במקום מרכזי.
- **מערכת התחברות אמיתית** לאדמין (הצפנת סיסמה נכונה + session/JWT).
- **שירות שליחת מיילים** (למשל Resend/SendGrid) לטיפול בטופס הפנייה במקום mailto.
- **אחסון תמונות בענן** (למשל S3/Cloudflare Images) במקום base64 בדפדפן.
- **אחסון ואירוח** (למשל Vercel/Netlify) עם דומיין משלכם.

הקוד הנוכחי בנוי בצורה מודולרית (`js/data.js` הוא שכבת הנתונים היחידה) כך שקל יהיה להחליף בעתיד את שכבת ה-localStorage בקריאות API אמיתיות מבלי לשנות את שאר האתר.
